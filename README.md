# social-proxy-robot
Overview
An expressive social proxy robot developed to investigate social presence and remote participation in hybrid learning environments.
Key Features
- Expressive head and body movements
- LED-based social signals
- Smartphone-based audio/video communication
- Microcontroller-based movement control
Technologies
Arduino, Python, servo motors, motor drivers, embedded electronics.
Evaluation
Evaluated with 18 participants, achieving a System Usability Scale score of 69.38.
